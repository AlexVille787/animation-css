# Collapsible Widget

Виджет "Collapsible" (сворачиваемый контейнер) на чистом JavaScript с плавной анимацией раскрытия/сворачивания.

## Демо

🔗 [Живая демонстрация](https://alexville787.github.io/animation-css/)

## Возможности

- Плавное раскрытие и сворачивание контента (без использования `opacity`)
- Кнопка "Collapse" с фиксированным текстом (не меняется)
- Ссылка "Copy" в правом нижнем углу (всегда видна)
- Анимация через `max-height` + `transition`
- Сборка через Webpack
- CI/CD через GitHub Actions с автодеплоем на GitHub Pages

## Технологии

- **JavaScript (ES6+)** — класс `Collapsible`
- **CSS3** — анимация через `max-height` и `transition`
- **Webpack 5** — сборка проекта
- **Babel** — транспиляция JS
- **ESLint (airbnb-base + prettier)** — линтинг
- **GitHub Actions** — CI/CD
